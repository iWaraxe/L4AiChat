# 🎓 Interactive Learning Tutorials

Welcome to the comprehensive Spring AI learning experience! This tutorial series is designed to take you from basic concepts to advanced AI application development.

## 📚 Learning Path Overview

### **Beginner Track** (Modules S1-S3)
- **Duration**: 2-3 hours
- **Prerequisites**: Basic Spring Boot knowledge
- **Outcome**: Build simple AI-powered chat applications

### **Intermediate Track** (Modules S4-S6)  
- **Duration**: 3-4 hours
- **Prerequisites**: Complete Beginner Track
- **Outcome**: Develop production-ready chatbots with state management

### **Advanced Track** (Modules S7-S9)
- **Duration**: 4-5 hours
- **Prerequisites**: Complete Intermediate Track
- **Outcome**: Master advanced AI patterns and architectures

## 🚀 Quick Start Guide

### Step 1: Environment Setup
```bash
# Clone the repository
git clone <repository-url>
cd L4AiChat

# Set up your OpenAI API key
export OPENAI_API_KEY=your-api-key-here

# Build the project
./mvnw clean install

# Run tests to verify setup
./mvnw test
```

### Step 2: Choose Your Learning Path
- **🟢 New to Spring AI?** → Start with [Tutorial S1: First Steps](./S1-first-steps.md)
- **🟡 Have Spring Boot experience?** → Jump to [Tutorial S3: Context Management](./S3-context-management.md)
